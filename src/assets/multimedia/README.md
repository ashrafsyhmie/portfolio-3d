# Multimedia projects

Add your own finished work here. Each file becomes one project in the Multimedia section.

- Images: PNG, JPG, JPEG, WebP, GIF, AVIF.
- Videos: MP4 (H.264 recommended) or WebM, with native playback controls and no autoplay.
- Uppercase extensions and subfolders are supported.
- Filenames become titles: `Campus-event-poster.png` displays as “Campus event poster”.
- Files sort by name, with numeric ordering. There is no fixed count limit.
- Local preview updates automatically; published websites need a rebuild and redeploy.

Use web-sized images and compressed videos. Provide captions within videos that contain speech.
Until you add files, the section displays a “coming soon” message.
