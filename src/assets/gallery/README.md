# Gallery pictures

Drop pictures into this folder (subfolders work too). Supported extensions:
PNG, JPG, JPEG, WebP, GIF, and AVIF, lowercase or uppercase.

The local Vite preview automatically updates when images are added or removed.
There is no fixed image-count limit; only the active picture and its neighbors render.
Large image files still increase build size, so resize photos for the web.

Pictures sort by filename with numeric ordering. Use names such as
`01-campus-day.jpg` and `02-team-photo.jpg` to set the order. Filenames become captions.

Rebuild and redeploy the website after changing pictures on a published site.
